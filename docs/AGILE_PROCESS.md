# Agile Process Evidence Template

## Sprint cadence

- Sprint duration: 2 weeks
- Ceremonies: planning, daily sync, review, retrospective

## Sprint tracking format

- Goal:
- Start date:
- End date:
- Committed stories:
  - US-001 ...

- Delivered stories:

- Carry-over:

- Risks/blockers:
- Retro actions:

## User story format

- As a `<role>` I want `<capability>` so that `<value>`.
- Acceptance criteria:
  - Given / When / Then

## Metrics to attach each sprint

- Planned vs delivered stories
- Defect count
- Lead time per story
- Build/test status
